# 系统进化记录机制

NeuxMind Robot OS 的每一次优化都要留下可追溯的记录，让下一轮（无论是人还是 Agent）知道：为什么这样设计、做了什么、验证到什么程度、还差什么。这是系统"自我进化"的记忆。

## 文件

| 文件 | 内容 |
|---|---|
| `EVOLUTION_LOG.md` | 按时间倒序的进化日志，每轮一条，简明 |
| `iterations/<日期>-iterNN.md` | 每轮的详细记录：目标、决策、分工、改动、验证、遗留 |
| `reviews/<日期>-iterNN-review.md` | 审查 Agent 的独立审查报告 |
| `DECISIONS.md` | 架构决策记录（ADR），只追加，不改写历史 |

## 每轮记录格式

```markdown
## 第 NN 轮 · YYYY-MM-DD · <一句话主题>
- 目标：
- 关键决策：（链接 DECISIONS.md 条目）
- 分工：Agent → 交付
- 改动：目录/文件级摘要
- 验证：测试数量与结果；哪些是真实验证，哪些是仿真/替身
- 遗留：→ 进入下一轮候选
```

## 规则

- 只追加，不删除历史条目；推翻旧决策时新增一条 ADR 说明原因。
- 验证必须区分"协议/仿真通过"与"真机/真模型/真支付通过"。
- 下一轮的目标优先从上一轮"遗留"和审查意见中选取。
