# 第 04 轮进化记录 · 2026-11-09 · 能力一致性测试、AI 本体适配助手 v2、桌面开箱即用（0.10.0 → 0.11.0）

## 目标
1. 能力一致性测试套件：任何本体接入后，用 static / dry / motion 三级测试验证它是否真的符合能力标准，输出 `conformance.report.v1`。
2. AI 本体适配助手 v2：桌面「本体适配」四阶段工作流；适配器脚手架；ROS 2 替身。
3. 云端记录一致性摘要，模型可要求最低一致性级别（`require_level`）。
4. （本轮插入，来自用户试用反馈）桌面版开箱即用：不开终端、不复制令牌、不手打路径。

## 关键决策
- **ADR-019：一致性测试本身绝不能成为危险源。** 测试会让机器人运动，所以它必须比被测本体更保守：不清除他人锁存、dry 永不位移、任何失败即停车锁存、自报数据不采信。
- `arm.joint_position` 新增 `joint_names`（v1.1，可选；v2 计划必填）。未声明时，任何组件不得假定 `joint.state` 顺序就是指令顺序：套件 blocked，运行时拒绝动作块。
- dry 级不向机械臂发送任何目标（只证明请求校验与拒绝）。
- 报告写明信任边界（`trust`）：报告由与适配器同进程的套件自报，不能替代现场验收；仿真证据永不作为现场证据（ADR-011）。
- 「直接运行技能」只对仿真机器人开放；真机仍走「机器人应用 → 现场测试 → 部署」。

## 用户反馈带来的改动（ux01）
用户演示时发现：装好软件什么都做不了、要从终端复制令牌、装技能要手打路径、看不到机器人动、术语看不懂。本轮改为：
- 「我的机器人」三种接入方式各配一句用途说明；「添加仿真机器人」一键启动并连接。
- 能力卡片先写中文名和「这能让机器人做什么」。
- 示例技能库：逐个标明这台机器人能否使用及原因。
- 授权运行后实时观看（四足俯视轨迹 / 机械臂关节值），停止即锁存。
- 云平台连不上时直接说明原因。
- `scripts/build_macos.py` 把运行时、规范和示例技能打进 App，不需要 Python。
- 一键演示脚本 `scripts/demo.py` 与演示指南 `docs/DEMO.md`。

## 教训
- 修复会引入新缺陷（R4b-01 来自修复 2）。安全相关修复必须再复审，直到一轮复审无 P0/P1。
- 「能跑通」不等于「用户能用」。本轮最有价值的反馈来自用户亲自演示；今后每轮发布前按用户路径走一遍。
