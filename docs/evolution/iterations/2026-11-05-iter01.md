# 第 01 轮进化 · 2026-11-04 ~ 11-05 · 从桌面控制台到跨本体机器人 OS

## 1. 起点（0.7.1）

Mac 桌面开发管理台：项目、版本、证据门禁、额度账本、AI 本体调查都很严谨；但机器人端只有约 140 行转发网关，能力是自由字符串（技能无法跨本体复用），注册与计费在本机 SQLite（商业化不成立），没有开发者 SDK，从未连接真机。

## 2. 本轮目标

1. 定义跨本体的唯一契约：标准能力接口。
2. 建三层：端侧运行时、云平台、SDK；桌面端保留并接入新层。
3. 建立多 Agent 协作与进化记录机制。
4. 证明同一技能可在不同本体（仿真）上复用，不兼容时安装前就被拒绝。

## 4. 关键决策（见 DECISIONS.md）

ADR-001 三层+契约 · 002 标准能力是跨本体唯一机制 · 003 spec/runtime 零依赖 · 004 预留→计量结算 · 005 目录所有权并行 · 006 法币买点数、点数买模型 · 007 预留按最坏上界 · 008 平台运营员与现场操作员分离 · 009 急停锁存 · 010 技能本轮无沙箱 · 011 现场证据失败即关闭 · 012 超额按预留上限扣费（部分推翻 007）· 013 消费与运营以邮箱验证为前提 · 014 账户所有权=本人会话+邮箱令牌 · 015 停车通道解耦、限值冻结。

## 5. 审查发现与处理

| 编号 | 级别 | 问题 | 处理 |
|---|---|---|---|
| C-01 | P0 | 白名单邮箱可被抢注成为平台运营员（实测自加 10 亿额度） | 邮箱验证；运营员需验证+命令授予 |
| C-02 | P0 | 会话透传参数致免费用量（1000 预算用 45070、扣费 0） | 参数白名单、n=1、服务端输出上限、超额按上限扣费 |
| R-01 | P1 | 停止+reset 后在途旧调用仍驱动本体 | 停止代数 |
| R-02/03 | P1 | 清单限值不校验，负数导致反向满速；限位长度不足漏检 | spec 失败即关闭 + 监督器再校验 |
| R-04 | P1 | 读不到关节状态时跳过动作块限速 | 失败即关闭 |
| R-05 | P1 | 空闲连接耗尽线程可挤掉 stop | 连接上限、请求期限、停止专用名额 |
| R-06 | P1 | ROS2 发送中的导航目标停不掉 | 回调取消 + 取消全部目标 |
| R-07 | P1 | 桌面端无法解除急停 | `/v1/reset` + 桌面"解除急停" |
| R-08 | P1 | 仿真结果被记为现场证据 | 仿真报告隔离，不能发布/启动 |

| N-02/03/04/06 | P2 | 慢盘拖延致锁存后指令下发；看门狗被锁住；运行中改限值；动作块 dt 无上限 | 到达时代数；解耦停车通道；冻结限值+漂移检测；dt/步数/时长上限 |

## 7. 协作经验（已写入 AGENT_COLLABORATION.md）

- 审查 Agent 在共享工作区做变异测试，导致同时运行的 SDK 测试偶发失败 → 会改代码的测试必须在 git worktree 中进行。
- 独立审查非常值得：两个 P0 和多数 P1 都不是开发 Agent 自己能发现的；复审又抓到了第一次修复引入的新绕过（N-01）。
- P0/P1 修复并复验之前不发布。
