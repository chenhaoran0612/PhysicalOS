## 3. 关键决策与契约
- 平台基线：spec/runtime/sdk `requires-python >= 3.10`；非 root 下沙箱"尽力而为"并在 `/v1/status` 如实报告；技能用户必须能执行解释器。
- `model.install` 由运行时原生提供；`model_runtimes` 与其 `params.runtimes` 一致；已安装模型以 SHA-256 标识，可附目录 ID。
- 工程助手云网关路径：本地账本零调用；Codex 0.146.1 请求字段逐项评估放行（`prompt_cache_key` 按组织重写、`store` 只能为 false 等）；上游终止事件在结算后转发。
- 协作规则第 9 条：有界执行与卡住 Agent 的接管。

## 6. 协作经验
- **Agent 卡住**：桌面 Agent 启动的浏览器 fixture 挂起，3 小时无文件变化且不回应消息。处理：停止 → 验证其未提交工作 → 新 Agent 接手（20 分钟完成）。已写入协作规则第 9 条。
- **只有真实二进制才能发现的问题**：Q3-03 令牌落盘在替身测试中永远不会出现。今后涉及第三方二进制的路径必须至少一条真实二进制测试。
- 审查 Agent 主动承认未覆盖的范围（C 项未写新逃逸攻击），总指挥据此判断风险可接受（第 02 轮已专项实证）。
