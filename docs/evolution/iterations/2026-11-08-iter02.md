## 5. 复审实证攻击（发布闸门）
以真实恶意技能经 HTTP 网关安装运行：伪造管道消息、超限参数、旧代数指令 → 适配器 0 条；死循环屏蔽 SIGTERM、灌管道、fork+setsid 期间 `/v2/stop` 6–91 ms 返回且先停车；令牌、运行时 /proc、状态目录不可读，setuid / ptrace / 抬 rlimit 被拒；Q2-01、Q2-04 修复实证有效；无进程 / cron / 受保护目录持久化。

**已知问题（进入第 03 轮首项）**：`test_stop_within_one_second_under_many_half_open_connections` 约 1/15 偶发失败——失败点不是停止（停止断言每次都通过，<1 s），而是"连接满时普通请求应立即 503"偶尔得到 200，说明连接上限计数在 stop 驱逐空闲连接后存在时序窗口。总指挥已让测试在 stop 后补满连接（失败率从约 1/3 降到约 1/15），未放宽断言；根因交给运行时 Agent。
