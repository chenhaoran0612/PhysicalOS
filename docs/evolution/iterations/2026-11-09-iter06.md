# 第 06 轮进化记录 · 2026-11-09 · 安全拒绝说真话、锁存守护看得见慢蠕动（0.12.0 → 0.13.0）

## 目标
关闭第 05 轮审查的 5 个 P2（Q5-01..05）与首次用户走查的 8 个困惑点。

## 改动
### 运行时（abab971）
- **慢速蠕动**：锁存后记快照，离开超过 5 cm / 0.05 rad 即再停。1.5 cm/s 蠕动 10 分钟位移 9 m → 1 m；静止本体误报 0。
- **反馈不可用**（NaN、长度不符、`velocity:null`、读取卡住、关节名乱序）按"可能在动"处理并再停。30 s 位移 8.4 m → 0。
- **参数设备端校验**：所有入口（直接运行、`/v1/start` 含旧 release、deploy/evaluate/validate）按 skill.json 检查范围、可选值、长度；越界 400 `param_out_of_range`，适配器调用 0 次。示例技能声明了范围。
- **复位卡住的出路**：`/v1/status` 给出时长与提示；README 写明"确认安全 → 重启运行时（锁存保留）→ 解除急停"。
- 适配器可声明 `stop_settle_s`（受控坐下的刹停宽限，1–5 s）。

### 桌面（ux04 637d63d + 5da149a）
- 错误分类先看错误码、再看 HTTP 状态、最后才看文字；安全拒绝永不被说成"服务出错，稍后重试"或"网络超时"（95 条表驱动检查）。
- 复位被拒或卡住时显示真实原因与出路；仿真机器人可"重启仿真机器人"（锁存保留）。
- **复位卡住时如实告知**（来自本轮审查 Q6-03，发布前修复）：上一次复位仍在执行，完成后急停可能自动解除、本体可能动作，请保持远离；提供"停止（取消那次复位）"。
- 参数越界在发送前标在对应字段上；设备返回的字段级拒绝也映射到字段。
- 单位只取自 skill.json，不再按参数名猜。
- 首次用户的 8 个困惑点：预检参数中文化、能力 ID 换中文名、第一屏不出现接口地址、机器人名代替内部编号、授权勾选有说明、"运行技能"变灰时写明原因等。
