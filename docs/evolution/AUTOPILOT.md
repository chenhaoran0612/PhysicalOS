# 自主进化模式（Autopilot）

> 2026-11-08 用户指示：总指挥完全自主地持续优化整个项目，不征求意见，一直进行，直到用户明确叫停。

## 运行规则

1. 每轮遵循 `AGENT_COLLABORATION.md` 的流程：契约 → 并行开发 → 合并 → 独立审查 → 修复 P0/P1 → 复验 → 进化日志 → 同步到用户 Mac → 立即开始下一轮。
2. 一轮结束时，下一轮目标从：上一轮遗留、审查意见、路线图 中由总指挥自行选取；写入本文件的"轮次队列"。
3. 进度可见：各 Agent 维护 `PROGRESS.md`；总指挥约每 15 分钟同步 `docs/evolution/live/STATUS.md` 到用户 Mac，并发一条简短进度。
4. 自主但不越界——以下事项即使在自主模式下也不做，记录为"需要用户"清单：
   - 推送到外部 git 仓库、发布到公网、产生真实费用（付费模型调用、真实支付、云资源）；
   - 删除用户 Mac 上的文件（文件夹不允许删除；同步只新增/覆盖）；
   - 连接或驱动真实机器人（需要现场安全确认）；
   - 修改 `dist/` 中已有安装包、修改与本项目无关的目录。
5. 每轮版本号：第 NN 轮发布为 0.(7+NN).0。
