# 登录应用时同时登录云平台（issue #36）

桌面应用的账号（`brainos/auth.py`，本机）和云平台账户（`cloud/`，资料库、钱包、模型都在这里）是两套邮箱 + 密码账户。
以前登录应用之后，打开“资料库”或设备档案里的“资料”还要再登录一次云平台。现在登录应用时一并完成。

## 行为

- **登录、注册、重置密码**这三处，应用手里有密码的那一刻，用同一邮箱和密码登录云平台。
  云平台上没有这个邮箱的账户时自动注册（名字用应用账号的名字）。
- 云平台地址还没填过时，使用默认地址（这台电脑上的云平台 `http://127.0.0.1:8800`，可用
  `NEUXMIND_DEFAULT_CLOUD_URL` 改）；连不上就不填、不登录，应用照常登录。
- “保持登录”会一并传给云平台（`remember: true`），云平台会话与应用会话一样保持 30 天；不勾选时两边都是 12 小时。
- 上传资料需要云平台邮箱已验证。开发环境的云平台（记录型邮件发送器）在注册结果里直接给出验证令牌，
  应用当场完成验证；正式云平台会发验证邮件，验证前“云平台账户”页照常显示“邮箱未验证”。
- 密码只在这几次请求里使用，不保存、不写日志、不进入页面数据。云平台会话令牌仍只在工作空间的凭据文件里。
- 用户自己在“云平台账户”页做的事优先：手工登录了另一个云平台账户、手工退出、修改了云平台地址，之后都不会被自动登录替换，
  也不会因此被要求重新登录应用。

## 旧版本留下的登录状态

这个版本之前登录的应用会话没有云平台登录，应用也没有密码可以补登。应用启动时（`GET /api/me`）检查：

| 情况 | 结果 |
|------|------|
| 云平台已登录且令牌有效 | 保持，什么都不问 |
| 旧会话，云平台没有登录（或令牌已失效），云平台连得上 | 退出这次登录，登录页上方说明“从这个版本起……请重新登录一次” |
| 旧会话，云平台连不上 | 保持，下次启动再检查 |
| 本版本的会话，登录时登上的云平台后来到期 | 退出这次登录，登录页说明“云平台登录已到期” |
| 本版本的会话，登录时云平台没登上（密码不同、连不上等） | 保持；资料页写明原因 |
| 用户手工退出了云平台 | 保持（不会为此退出应用）；下次登录应用时会再次登录云平台 |
| 云平台是不认识 `remember` 的旧版本（会话只有 12 小时） | 保持；资料页提示「重新登录」，不在每次启动时退出 |

每次登录都会记下“这次登录已经走过自动登录”（会话令牌的 SHA-256，表 `cloud_login_sessions`），
所以不会为了重新登录也解决不了的原因反复退出。

应用开着的时候云平台登录到期：资料页显示“云平台登录已到期”，给出「重新登录」（退出应用回到登录页）和「只登录云平台」。

## 没有自动登上的原因（资料页、“云平台账户”页会显示）

| `auto_login.status` | 含义 |
|---------------------|------|
| `password_mismatch` | 云平台上已有这个邮箱的账户，密码和应用密码不同。用云平台密码登录一次即可 |
| `claim_sent` / `email_pending_verification` | 这个邮箱在云平台上被一个未验证的账户占用 |
| `cloud_unreachable` | 连不上云平台 |
| `rate_limited` | 云平台暂时限制了登录尝试 |
| `manual` / `signed_out_by_hand` | 用户自己管理云平台登录（手工登录或改地址 / 手工退出） |

在应用里**修改或重置密码不会改云平台的密码**（云平台只能凭邮件重置）。之后登录应用时云平台密码对不上，
状态是 `password_mismatch`；已有的云平台会话不受影响，到期后需要用云平台密码登录一次（到期不会让应用退出登录）。

## 开关

- `Application.cloud_auto_login` 默认关：测试用 `Application(...)` 直接起的服务不会去碰这台电脑上真实的云平台。
- 启动入口 `brainos.server.main()`（桌面应用、`python -m brainos.server`、`scripts/demo.py`）打开它；
  `NEUXMIND_CLOUD_AUTO_LOGIN=0` 关闭。用启动入口跑验收脚本时请设 `NEUXMIND_CLOUD_AUTO_LOGIN=0`
  或把 `NEUXMIND_DEFAULT_CLOUD_URL` 指向一个没有服务的端口。

## 云平台一侧

`POST /auth/login`、`POST /auth/register` 接受 `remember: true`（只认布尔值 `true`），会话有效期改用
`NEUXMIND_SESSION_REMEMBER_TTL_SECONDS`（默认 2592000，即 30 天）。旧的云平台不认识这个字段，会话仍是 12 小时，
到期后应用在下次启动时要求重新登录。

## 代码与测试

- `brainos/cloud_auto_login.py`：登录云平台（`sign_in`）、会话标记与启动检查（`CloudAutoLogin`）、页面用的状态（`view`）。
- `brainos/server.py`：三处登录之后调用 `cloud_login.signed_in`；`/api/me` 调用 `cloud_login.stale_session`。
- `web/cloud_auto_login.js`：未登录提示（`cloudSignInNotice`）、“云平台账户”页的说明、`cloudSignInKey`（同一账户重新登录后资料列表重新读取）。
- `web/account.js`：登录页上方的说明（`.auth-note`）。
- 测试：`tests/test_cloud_auto_login.py`（真实云平台应用，回环端口）、`cloud/tests/test_remember_login.py`；
  界面验收 `node tests/cloud_auto_login_browser.cjs CONFIG.json [截图目录]`（夹具 `tests/cloud_auto_login_browser_fixture.py`）。
