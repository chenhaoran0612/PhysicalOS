## 技能与配置

- 模块保留。标题旁边那句“这个品牌型号的机器人装了哪些技能……”删除。
- “技能列表是刚从这台机器人上读到的。”删除。列表不是从设备读到的时候（机器人没连接、读取失败），仍然写明“按控制台的安装记录显示：……”和原因；正在读取时仍然显示“正在读取这台机器人上的技能…”。
- 「重新读取」按钮删除。设备上的技能在以下时候读取：页面画出来时；这台机器人上又装了一个技能之后；上一次读取失败 30 秒之后页面再次画出来时。
- 「已连接 / 未连接」移到原来「重新读取」的位置（机器人这一块页头的右侧）。
- 每个技能多一行**运行信息**：在这台机器人上直接运行过几次、最近一次的时间和结果（正在发给机器人 / 机器人已开始运行 / 机器人拒绝了这次运行 / 请求没有发出 / 结果不明），被拒绝或没发出时带上原因；没有运行过写“还没有运行过”。数据来自控制台已有的运行记录（`operations` 里 `kind = skill_run`），没有新增记录。

运行信息只统计「直接运行技能」的记录。应用启动后由应用调用技能的情况，控制台没有逐个技能的记录，这里不显示。
