# 图标：一张表、一种画法、一个标志（issue #72）

更新：2026-11-27。对应 GitHub issue #72「整体 Icon 优化」。设计稿第 1 版经用户确认，标志选方案 A。

## 之前的问题

- 标志「n↗」是两个文字字符叠出来的，形状取决于电脑上的字体；安装包图标是另外画的一份，形状不同。
- 侧边栏图标是直角线条（粗细 1.6），和页面里圆角的按钮、卡片不是一个风格。
- 七个页面没有自己的图标（仿真试运行、平台模型与算力、用量与账单、云平台账户、技能发布、技能加载、资料库），显示的都是「机器人应用」的图标。
- 返回、打开、完成、关闭、菜单、搜索、编辑、修复用的是文字符号（← ↗ ✓ × ☰ ⌕ ✎ ⚒），大小粗细各不相同。
- 五张本体类型示意图是第三种画法。

## 画法

| 规则 | 值 |
| --- | --- |
| 网格 | 24 × 24，四周留 2，图形画在中间 20 以内 |
| 线条 | 粗细 1.75，端点和拐角都是圆的，不填色 |
| 圆角 | 2 |
| 颜色 | 跟随旁边的文字（`currentColor`）：深绿侧边栏里是浅色，选中时是深绿，页面里是品牌绿 |

## 文件

| 文件 | 内容 |
| --- | --- |
| `web/icons.js` | 图标表 `NX_ICON_PATHS`（名字 → 路径）、文字符号对照表 `NX_GLYPHS`、页面渲染后把符号换成图标的 `nxDrawGlyphs` |
| `web/icons.css` | 统一的线条样式、标志（`--nx-mark`）、被替换符号的样式 |
| `desktop/icon.swift` | 安装包图标，画的是和 `--nx-mark` 同一组笔画 |
| `web/robot_images/type-*.svg` | 五张本体类型示意图，路径取自图标表的 `manipulator`、`wheel_legged`、`quadruped`、`biped`、`other` |

两个新文件在 `web/index.html` 末尾加载（要晚于 `style.css` 和 `app.js`），`brainos/server.py` 只多了一行静态文件表。各页面的渲染代码没有改动。

## 怎样生效

- **图标表**：`web/app.js` 的 `icon(k)` 从它自己的 `icons` 对象取路径。`icons.js` 把 `NX_ICON_PATHS` 合并进这个对象，所以所有已经在用 `icon('plus')`、`icon('models')` 的页面自动换成新图标，侧边栏每一页也有了自己的图标。`icon()` 只画一个 `<path>`，所以表里的矩形和圆都写成路径（`nxRect`、`nxCircle`）。
- **文字符号**：页面内容每次变化后，`nxDrawGlyphs` 把符号换成表里的图标（和 `web/dropdown.js` 接手 `<select>` 的做法一样）。原来的字符留在页面里，只是看不见，所以读屏、复制和测试脚本读到的文字和以前一样（例如 `.tw-back` 的文字仍是「← 全部任务」）。
  - 单独出现的符号都换：← ↗ ↑ ↓ ✓ × ✕ ✗ ☰ ⌕ ✎ ⚒ ⟳ ■。
  - 一行文字开头的 ← ✓ ✗ ✕、结尾的 ↗ 也换（「← 返回」「开发指南 ↗」）。
  - 句子中间的符号是文字，不换（「我的机器人 → 能力表」「2 × 3 点」「仿真四足机器人 ✓ 可用」）。
  - `<pre>`、`<code>`、输入框、下拉选项、日志行（`.log-item`，设备或助手写的原文）里的内容不动；个别地方要保留字符时，加 `data-nx-raw`。
  - 一行只画开头的第一个符号，画过的不再看第二遍；页面变化时只看新写入的内容，不重扫整页。
  - 两处同一个符号意思不同：未登录时头像位置的 ↗ 画成人像，提示条开头的 ↗ 画成提示。
- **标志**：`.brand-mark` 用 `--nx-mark` 做遮罩，颜色还是原来的（侧边栏和登录页深色区是浅绿，浅色底上是品牌绿）。原来的两个字符不显示。

## 新页面、新按钮怎么用

- 侧边栏加一页：在 `NX_ICON_PATHS` 里加一个和路由同名的图标。`tests/icons_logic.cjs` 会检查每一页都有自己的、不和别页重复的图标。
- 按钮里要图标：`button(icon('plus') + ' 添加', …)`，或直接写 `nxIcon('edit')`。
- 不要再用文字符号当图标。确实写了，只要在上面的对照表里，也会被画成图标。

## 测试

| 测试 | 检查什么 |
| --- | --- |
| `tests/icons_logic.cjs` | 每页有自己的图标；原有图标名都在表里；路径都在 24 网格内；符号的切分规则；标志在页面和安装包里是同一组笔画 |
| `tests/test_icons.py` | 两个文件能被取到、在 `style.css` 和 `app.js` 之后加载；五张类型图的画法；运行上面的逻辑检查 |
| `tests/icons_browser.cjs` | 登录页和侧边栏的标志；侧边栏每个图标的路径和线条；每一页都没有残留的文字符号；对话框的关闭、窄屏的菜单按钮；后写入的内容也会被画，重复执行不变。夹具：`tests/ux01_browser_fixture.py`，`BRAIN_BROWSER=webkit` 可在 WebKit 上跑 |

## 没有做的

- 句子中间的 ✓ ✗（仿真页「✓ 可用 / ✗ 不可用」）仍是文字。
- 下拉框、组合框的小箭头和勾（`web/dropdown.js`、`web/combo.js`）是各自画的 12 / 16 网格图形，没有并入这张表。
- 安装包图标要重新打包才会更新。
