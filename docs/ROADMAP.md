# 路线图

> 每轮进化结束、每个 issue 合并时更新。✅ 完成（注明验证级别）· 🟡 进行中 · ⬜ 未开始

- ✅ 能力接口标准 v1 + manifest v2 + 技能包 v1（第 01 轮，单元测试级）
- ✅ 端侧运行时：HAL、安全监督（限幅/看门狗/急停锁存/停止代数）、技能运行时、v1/v2 网关、仿真四足/机械臂（第 01 轮，仿真级；真机未验证）
- ✅ 云平台：账户/组织/API Key、邮箱验证、钱包账本、模型市场、推理网关、支付接口（第 01 轮，替身级；真实支付/上游未接）
- ✅ SDK + `nx` 命令行 + 技能模板（第 01 轮，5 分钟上手实跑通过）
- ✅ 桌面端：仿真证据隔离、解除急停（第 01 轮修复）
- ✅ 桌面端接入：能力表、技能包安装、云端登录与钱包（第 02 轮）
- ✅ 异步现场测试、网关会话流式、技能进程沙箱（第 02 轮；沙箱经实证攻击，第三方技能前仍需 uid/文件系统/网络隔离）

## 阶段 2：第一台真机（第 04 轮起）
- ✅ 能力一致性测试套件（static / dry / motion）+ AI 本体适配助手 v2：SSH 调查 → 适配器初稿 → 能力对照测试（第 04 轮，仿真与 ROS 2 替身级；真机未验证）
- ✅ 桌面开箱即用：一键仿真机器人、示例技能库、授权运行并实时观看（第 04 轮 ux01）
- ✅ 用户路径审计与修复（第 05 轮）；安全拒绝说真话、错误分类（第 06 轮）
- ✅ 锁存守护：慢蠕动、反馈失效、真实传感器噪声下不误报，且所有可比场景不比 0.13.0 弱（第 05–07 轮，仿真与对照场景级；阈值未经真机标定）
- 🟡 SSH 经一台跳板机接入（两跳指纹固定）+ 粘贴 ssh 命令自动填表（含嵌套写法 `ssh 用户@跳板机 'ssh 名称'`，目标名称按跳板机上的 SSH 配置解析）+ 真机只读实时状态（issue #3，已合入 integration；界面流程替身级；只读状态经公网跳板机在一台四足机器人上验证）
- 🟡 连接后初始化硬件扫描，并在逐条审批下修复扫描出的问题（驱动、权限、网络等），内置 Skill `hardware-init`（issue #2，已合入 integration；只读扫描在一台 Jetson Orin NX 真机上验证，修复会话为替身级）
- ⬜ 选定首批本体：一台四足（可用巡检机器狗）+ 一台机械臂
- ⬜ ROS 2 桥接实机验证；厂商 SDK 适配器
- ⬜ 机器人 HTTP 适配服务经跳板机转发；多跳；ROS 层数据（电量、位姿）进入实时状态（#3 暂不包含）
- ⬜ 现场测试报告接入运行时真实遥测
