NeuxMind Robot OS 0.17.0 — macOS Apple Silicon 开发预览

要求：Apple Silicon（M1 或更新），macOS 13 或更新。
安装：将 NeuxMind Robot OS.app 拖入 Applications，然后打开。
也可以使用同版本 .pkg 安装包。
不需要安装 Python、Node 或其他开发工具。

当前为本地签名的开发预览包，未完成 Apple Developer ID 签名及公证。
若 macOS 阻止首次启动，可在确认来源后通过“系统设置 → 隐私与安全性”允许打开。
此版本尚未验证 Intel Mac；Windows 版后续处理。

首次打开先显示登录 / 注册页：注册要填邮件里的 6 位验证码，登录后可创建项目；以前注册的账号直接登录。
没有配置邮件服务时验证码不会发出，而是写在本机的 mail-outbox.txt 里，注册页会显示它的位置。
没有真机也能马上试用：在“我的机器人”点“添加仿真机器人”（四足或机械臂），
从“安装技能包”里的示例技能安装巡逻或挥手，授权后运行并在“实时状态”里观察；不需要终端。
仿真机器人随应用启动和退出，结果都标注为仿真，不能作为现场证据。
菜单“连接平台服务…”可配置运营方提供的 HTTPS 工作台地址。
平台模型、算力、仿真和计费目录需要配置真实服务；不随安装包虚构资源或模型权重。
本机数据保存于 ~/Library/Application Support/NeuxMind Robot OS/，更新应用不会删除数据。
可先输入 SSH 信息（直连或经一台跳板机，也可以直接粘贴一条 ssh 命令），由工程助手调查本体并保存档案；接入后可查看真机的只读实时状态。
调研入口按状态打开：没调研过是开始表单，调研中是进展，调研完是报告。调研不限 Token 和时间，由你决定何时停止。
报告上可以重新调研（先扫描硬件，再完整调研一遍，生成新的档案版本），也可以用对话的方式让助手修复问题。
连接成功后会先做一次只读的硬件扫描，列出硬件清单和需要处理的问题；可以让助手修复，每条会修改设备的命令都要你批准。工程任务可以生成适配器和 Harness 代码。
工程助手的大模型只对接 TokenFans：调用前请在“云平台账户”页连接 TokenFans 并选择默认模型（费用从 TokenFans 账户余额扣除）。真正执行机器人任务仍需对应驱动与实机验收。
界面默认不显示代码和原始数据：数据显示成“名称—值”，命令和原始输出折叠在“展开查看…”里；要你批准的命令会直接显示。
开源工程运行时随包提供，许可证可在菜单“开源许可…”中查看。

“工程扩展”可创建或导入 Skills、配置 HTTP MCP 服务并选择工具。
工程任务按次选择扩展；MCP 调用在执行前显示参数供用户决定。
