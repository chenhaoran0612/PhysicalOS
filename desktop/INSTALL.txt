NeuxMind Robot OS 0.20.0 — macOS Apple Silicon 开发预览

要求：Apple Silicon（M1 或更新），macOS 13 或更新。
安装：将 NeuxMind Robot OS.app 拖入 Applications，然后打开。
也可以使用同版本 .pkg 安装包。
不需要安装 Python、Node 或其他开发工具。

当前为本地签名的开发预览包，未完成 Apple Developer ID 签名及公证。
若 macOS 阻止首次启动，可在确认来源后通过“系统设置 → 隐私与安全性”允许打开。
此版本尚未验证 Intel Mac；Windows 版后续处理。

首次打开先显示登录 / 注册页：注册要填邮件里的 6 位验证码，登录后可创建项目；以前注册的账号直接登录。
没有配置邮件服务时验证码不会发出，而是写在本机的 mail-outbox.txt 里，注册页会显示它的位置。
没有真机也能马上试用：在“我的机器人”点“添加仿真机器人”（四足或机械臂），
从“安装技能包”里的示例技能安装巡逻或挥手，授权后运行并在“实时状态”里观察；不需要终端。
仿真机器人随应用启动和退出，结果都标注为仿真，不能作为现场证据。
菜单“连接平台服务…”可配置运营方提供的 HTTPS 工作台地址。
平台模型、算力、仿真和计费目录需要配置真实服务；不随安装包虚构资源或模型权重。
本机数据保存于 ~/Library/Application Support/NeuxMind Robot OS/，更新应用不会删除数据。
可先输入 SSH 信息（直连或经跳板机，跳板机可以有多级，最多 5 级，每一级的主机指纹逐个确认；也可以直接粘贴一条 ssh 命令，如 ssh -J a,b,c 用户@机器人），再选本体类型，由工程助手调查本体并保存档案。
本体类型来自“我的机器人”页面底部的本体类型清单：内置四足机器人和机械臂，可以添加和删除；还有设备在用的类型不能删除。以前登记的设备保留原来的类型，不在清单里的标为“旧类型”，可以在卡片上改。
通过 SSH 接入的机器人，卡片上直接显示在线或离线和最近一次心跳的时间（后台每分钟检查一次，连续 3 分钟没有应答才算离线，恢复后自动回到在线），不用打开“实时状态”。
真机卡片上的“设备档案”把系统、硬件、ROS 2（发行版、节点、话题、动作、服务）和资源占用合成一份，只读，第一次打开时读取，之后点“重新读取”才会再登录设备。
接入后的“实时状态”每分钟只读读取一次：系统数字之外，“硬件”页签列出全部设备及其驱动和工作状态，“软件”页签列出正在运行的系统服务、ROS 等机器人中间件进程、Docker 容器和占用资源最高的进程。
已接入的 SSH 机器人可在卡片的“配置连接”里直接改连接（地址、登录方式、跳板机）：密码和私钥不回显，留空沿用已保存的；地址变了要重新确认主机指纹；调研、修复或硬件扫描进行中也能改，不会打断正在运行的会话；把机器人改指向另一台机器时，正在运行的会话不会跟过去，要停止后重新开始。
接入了设备端运行时的真机，要先在卡片或详情的“安全限值”里填写最大线速度、最大角速度和运动指令超时；没填之前任何能力都不能让它运动，停止和读取状态不受影响。
“我的机器人”里真机的卡片可以“删除”：连同它的 SSH 连接、保存的登录信息、调研和修复记录一起从这台电脑上删掉，不会登录或改动机器人；正在调研、修复、扫描硬件或本体适配流程运行中时不能删。以它为目标的应用和流程记录保留。
调研入口按状态打开：没调研过是开始表单，调研中是进展，调研完是报告。调研不限 Token 和时间，由你决定何时停止。
报告上可以重新调研（先扫描硬件，再完整调研一遍，生成新的档案版本），也可以用对话的方式让助手修复问题。
连接成功后会先做一次只读的硬件扫描，列出硬件清单和需要处理的问题；可以让助手修复：默认勾选“默认允许执行”，命令通过产品检查后直接执行并留下记录，少数看不清的命令仍会先问你，也可以改为逐条批准；助手只做软件层面的修复，软件修不了的问题会标注为“等待现场处理”，现场处理并标注后才能再交给助手；修复同样不限 Token 和时间，由你决定何时停止。工程任务可以生成适配器和 Harness 代码。
登录云平台账户后，“资料库”页可以把手册、参数表、URDF 和驱动安装包上传到云平台（分片上传，中断后可以继续），并标明本体类型、厂家、型号和版本。
工程助手的大模型只对接 TokenFans：调用前请在“云平台账户”页连接 TokenFans 并选择默认模型（费用从 TokenFans 账户余额扣除）。真正执行机器人任务仍需对应驱动与实机验收。
界面默认不显示代码和原始数据：数据显示成“名称—值”，命令和原始输出折叠在“展开查看…”里；要你批准的命令会直接显示。
开源工程运行时随包提供，许可证可在菜单“开源许可…”中查看。

“工程扩展”可创建或导入 Skills、配置 HTTP MCP 服务并选择工具。
工程任务按次选择扩展；MCP 调用在执行前显示参数供用户决定。
